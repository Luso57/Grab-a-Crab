PIRATE SHIPWRECK

Triangles: 4092
Collection: PirateShipwreck

PirateShipwreck.blend: editable separate planks and decorations, flat shading, solid materials.
PirateShipwreck.fbx: 9 grouped meshes, applied transforms, triangulated, embedded color palette.
PirateShipwreck_Colors.png: 128x128 solid color palette, also supplied separately.

Import the FBX using Roblox Studio's 3D Importer. If the embedded palette is not picked up, import the supplied PNG and assign it as the mesh texture / SurfaceAppearance ColorMap. All FBX meshes share this palette and have matching UVs.
Set decorative MeshParts Anchored=true. Configure collision according to placement.

The source uses solid material colors; the export palette preserves those colors without detailed image textures.
